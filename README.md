# RokenS ART3 · Formations d'escadron / Squad formations (Last War)

**FR** — Créez un escadron mené par un chef d'escadron et formez un groupe de coéquipiers rattachés à lui, à qui vous donnerez simplement leur position.
Le chef se place en premier, puis chaque coéquipier reçoit une consigne simple (« 1 case au-dessus de RokenS », ↑1…).

**EN** — Create a squad led by a squad leader and form a group of teammates attached to them, then give each one their position simply.
The leader takes position first, then every teammate gets a simple direction ("1 cell above RokenS", ↑1…).

Langues / Languages : Français · English · 日本語 · Bahasa Indonesia (automatic detection + language buttons)

## Fonctionnalités / Features
- Formes automatiques (croix, X, étoile, bloc, carré, cercle, losange, V, triangle, lignes) proposées seulement si elles sont possibles avec le nombre de coéquipiers choisi
- 10 formes fun de 5 cases et 5 cœurs à taille fixe
- Dessin libre sur une grille, pivoter, miroir
- Jusqu'à 500 coéquipiers, pseudos personnalisés
- Plan à copier dans le chat d'alliance

## Utilisation
Ouvrir `index.html` dans un navigateur (aucun serveur, aucune installation), ou l'héberger avec GitHub Pages.

## Code
Un seul fichier, découpé en modules identifiés `E-MANUEL-xx` (état, formes, signalétique, carte, fiches, copie, sauvegarde, événements, langues).
Pour ajouter une langue : copier un bloc dans `E-MANUEL-09` et l'ajouter à `LANGS`.

Code écrit avec Claude (Anthropic). Traductions japonaise et indonésienne à faire relire par des locuteurs natifs.
